
# User Stories

## Doctor User Stories

### Doctor Story 1 – View Appointments
As a Doctor, I want to view my scheduled appointments so that I can manage my daily schedule and prepare for my patients.

### Doctor Story 2 – View Patient Information
As a Doctor, I want to view patient information associated with my appointments so that I can understand the patient's history and provide appropriate care.

### Doctor Story 3 – Update Patient Records
As a Doctor, I want to update patient medical records so that the patient's information remains accurate and up to date.

### Doctor Story 4 – Manage Appointment Status
As a Doctor, I want to update the status of an appointment so that the system reflects whether the appointment is scheduled, completed, or cancelled.

### Doctor Story 5 – View Patient Appointments
As a Doctor, I want to filter and view patient appointments by date so that I can efficiently manage my appointments for a particular day.

---

## Patient User Stories

### Patient Story 1 – Register/Login
As a Patient, I want to securely log in to the system so that I can access my personal information and healthcare services.

### Patient Story 2 – View Profile
As a Patient, I want to view my personal and medical information so that I can verify that my information is correct.

### Patient Story 3 – Book Appointment
As a Patient, I want to book an appointment with a Doctor so that I can receive medical care at a convenient time.

### Patient Story 4 – View Appointments
As a Patient, I want to view my upcoming and previous appointments so that I can keep track of my healthcare schedule.

### Patient Story 5 – Cancel Appointment
As a Patient, I want to cancel an appointment when necessary so that the Doctor's availability can be updated.

### Patient Story 6 – View Doctor Information
As a Patient, I want to view available Doctor information so that I can select an appropriate Doctor for my appointment.

---

## Admin User Stories

### Admin Story 1 – Admin Login
As an Admin, I want to securely log in to the system so that only authorized administrators can access administrative functions.

### Admin Story 2 – Manage Doctors
As an Admin, I want to add, update, and manage Doctor information so that the system contains accurate Doctor records.

### Admin Story 3 – Manage Patients
As an Admin, I want to view and manage Patient information so that patient records are maintained correctly.

### Admin Story 4 – Manage Users and Roles
As an Admin, I want to assign and manage user roles so that Doctors, Patients, and Administrators have appropriate access to the system.

### Admin Story 5 – Manage Appointments
As an Admin, I want to view and manage appointments so that I can monitor and maintain the overall appointment schedule.

### Admin Story 6 – View Dashboard
As an Admin, I want to view a dashboard containing important system information so that I can monitor the healthcare management system efficiently.

### Admin Story 7 – Maintain System Data
As an Admin, I want to maintain and update system data so that the application operates with accurate and reliable information.
