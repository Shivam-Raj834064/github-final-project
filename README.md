# Simple Interest Calculator

A simple calculator that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

Simple Interest = P × T × R / 100

Where:

- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest

## Usage

Run the `simple-interest.sh` script and enter the required values when prompted.

## Example

For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

Simple Interest = 1000 × 2 × 5 / 100

Simple Interest = 100

## Requirements

- Bash shell
- Linux, macOS, or Windows with a Bash environment

## Project Description

This project demonstrates a simple interest calculator implemented using a shell script. It accepts the principal amount, rate of interest, and time period as inputs and calculates the simple interest.
